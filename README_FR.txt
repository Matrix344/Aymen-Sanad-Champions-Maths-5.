AYMEN & SANAD – CHAMPIONS DES MATHS
Projet Android avec compilation APK en ligne via GitHub Actions.

Profils corrigés :
- Aymen : 13 ans
- Sanad : 9 ans

Le jeu est intégré dans l'application Android et fonctionne hors connexion.
L'application ne demande aucun compte et n'intègre aucune publicité.

OBTENIR L'APK EN LIGNE :
1. Créer un dépôt GitHub vide nommé Aymen-Sanad-Champions-Maths.
2. Décompresser ce ZIP sur le PC.
3. Envoyer tous les fichiers et dossiers du projet dans le dépôt GitHub.
4. Ouvrir l'onglet Actions du dépôt.
5. Lancer "Construire l'APK Android" avec le bouton Run workflow
   (ou attendre la compilation automatique après l'envoi sur main).
6. Ouvrir l'exécution terminée, descendre à Artifacts et télécharger
   Aymen-Sanad-Champions-des-Maths-APK.
7. Décompresser l'archive téléchargée : elle contient app-debug.apk.

IMPORTANT :
- Ce ZIP contient le projet source Android et le workflow de compilation.
- L'APK n'a pas encore été compilé ni testé sur un téléphone.
- La compilation en ligne nécessite un compte GitHub et l'envoi du projet.
- Cet APK debug est destiné à l'installation et aux essais. Pour Google Play,
  il faudra ensuite préparer une version release signée.
